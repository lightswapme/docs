The API is intentionally small: backend quote-driven swap creation and status polling.

## Current limits

| Area | Current behavior |
| --- | --- |
| API keys | Backend-only. |
| Rate limit | 120 requests per minute per API key. Exceeding it returns `429 rate_limited`. |
| Quote type | Exact-input floating quotes only. |
| Quote lifetime | Quotes expire 3 minutes after creation; see `expiresAt`. |
| Deposit window | Send the deposit before `deposit.deadline`, 4 hours after swap creation. |
| Commission | Flat 0.5% of completed swap volume, self-serve. See [Revenue sharing](/business/revenue-sharing). |
| Status updates | Poll `GET /swap/{id}`. No webhooks. |
| Destination memo | Optional on memo-capable networks (XRP Ledger, Stellar, Cosmos), up to 256 characters. Swaps fail with `unsupported_memo` when no route can carry a memo. |

## Integration defaults

- Poll active swaps every 30 seconds.
- Store the LightSwap swap ID with your own order ID.
- Treat all amounts as decimal strings.
- Refresh supported assets regularly instead of hardcoding asset lists.

## Fees and network costs

The API returns the route estimate and deposit instructions for the swap. Wallet, gas, and blockchain network costs are separate third-party costs and can change outside LightSwap.

## Support handoff

When you contact support, include:

- Your `externalId`, if you sent one.
- The LightSwap swap ID, if one exists.
- The deposit transaction hash, if the user has already sent funds.

Never include private keys, seed phrases, or full internal customer records.
