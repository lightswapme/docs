The Direct API lets your backend create swaps inside your own product experience. Your UI stays yours; LightSwap supplies the quotes, the deposit instructions, and the execution.

Start here if you're the engineer responsible for the integration.

## Base URL

```text
https://lightswap.me/api/partner/v1
```

## Get access

Activate a business account from **Account → Business** on [lightswap.me](https://lightswap.me/account). Your live API key is created instantly and shown once. Copy it and store it somewhere safe.

Then follow the [quickstart](/business/quickstart) to create your first swap in about five minutes.

For custom rates, test keys, or a dedicated rollout, [email us](mailto:partner@laptev-fzco.com?subject=LightSwap%20Direct%20API%20access).

## The six endpoints

| Endpoint | What it does |
| --- | --- |
| `GET /asset` | Lists supported assets, networks, decimals, and memo requirements. |
| `POST /address` | Validates a destination address before you quote. |
| `POST /quote` | Creates a short-lived quote for a pair and amount. |
| `POST /swap` | Creates the swap and returns deposit instructions. |
| `GET /swap` | Lists your swaps with status and date filters, pagination, and per-swap commission, for reconciliation. |
| `GET /swap/{id}` | Returns the current swap status. |

## What the API doesn't have yet

Being explicit saves you an integration surprise:

- No webhooks. Poll `GET /swap/{id}` instead.
- No browser-side keys. The API is backend-only.
- No refund endpoints. Refunds are handled case by case; see [Refunds](/integrations/direct-api/refunds).
- No per-request custom fees. Commission is the flat partner rate on your account.
- No fixed-rate quotes. All quotes are floating.
- No sandbox. Test keys run against live liquidity, so test with small amounts.
