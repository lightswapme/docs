---
title: "Widget"
description: "Embed the hosted LightSwap swap widget with an iframe, optional query parameters, and public attribution keys."
---

The widget puts the full LightSwap swap flow on your page with one iframe. No backend and no API key required.

Use it when you want users to swap on your site without building an API integration. For full control of the experience, use the [Direct API](/integrations/direct-api/introduction) instead.

<Note>
  Never put an API key in the widget. API keys are secret backend credentials. Widget keys are public attribution identifiers.
</Note>

## Quick start

<Steps>
  <Step title="Paste the iframe">
    Place the snippet where the widget should appear. No wrapper or custom parent component is required.
  </Step>
  <Step title="Set optional defaults">
    Set the starting pair, amount, theme, accent color, and locale in the iframe URL.
  </Step>
  <Step title="Add your widget key">
    Add `key=YOUR_PUBLIC_WIDGET_KEY` from **Account → Business** so completed swaps earn you commission. Without a key, the widget works but attributes nothing.
  </Step>
</Steps>

## Basic iframe

```html
<iframe
  title="LightSwap widget"
  src="https://lightswap.me/widget?from=BTC&to=USDT&amount=0.01&theme=light&accent=18e299&locale=en"
  style="border:0;display:block;width:441px;max-width:100%;height:570px;background:transparent;"
  scrolling="no"
  allow="clipboard-write"
></iframe>
```

`https://lightswap.me/widget` with no parameters is a valid URL and opens with LightSwap defaults.

## Add attribution

Copy your public widget key from **Account → Business** and add it as the `key` query parameter.

```html
<iframe
  title="LightSwap widget"
  src="https://lightswap.me/widget?key=YOUR_PUBLIC_WIDGET_KEY&from=BTC&to=USDT&amount=0.01&theme=light&accent=18e299&locale=en"
  style="border:0;display:block;width:441px;max-width:100%;height:570px;background:transparent;"
  scrolling="no"
  allow="clipboard-write"
></iframe>
```

Revenue-sharing terms live on your LightSwap account, not in the URL. Don't add custom fee or commission parameters to the widget URL.

You don't need to register a domain before embedding. Only place your widget key on pages where you want swaps attributed to your integration.

## Parameters

All parameters are optional.

| Parameter | Description |
| --- | --- |
| `key` | Public widget key for attribution. Omit it for unattributed usage. |
| `from` | Initial source token symbol, for example `BTC`. |
| `to` | Initial destination token symbol, for example `USDT`. |
| `amount` | Initial send amount. A positive decimal value, for example `0.01`. |
| `theme` | `light`, `dark`, or `auto`. Defaults to `auto`. |
| `accent` | Hex accent color without `#`, for example `18e299`. |
| `locale` | `en`, `es`, or `ru`. Defaults to `en`. |

<Tip>
  The snippet controls the widget width and height, so you can paste it directly into a page layout.
</Tip>

## Need a widget key?

Activate a business account from **Account → Business** on [lightswap.me](https://lightswap.me/account). The widget key is created instantly, and the attributed widget URL and embed code are always copyable from the tab.
