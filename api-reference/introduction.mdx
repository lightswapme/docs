This reference is generated from the LightSwap API OpenAPI specification. Each endpoint page documents request fields, response fields, and every error response with examples.

Use canonical lowercase `network` values such as `solana`, `base`, `bitcoin`, and `tron` when calling the API.

## Base URL

```text
https://lightswap.me/api/partner/v1
```

## Authentication

Every request requires the `x-api-key` header:

```http
x-api-key: <api_key>
```

## Response format

Successful responses return the endpoint payload directly. Error responses use a shared structure:

```json
{
  "error": {
    "code": "quote_expired",
    "message": "Quote has expired.",
    "details": {}
  },
  "requestId": "request-id"
}
```

The endpoint pages show which status codes each endpoint returns and which error codes come with them. [Statuses and errors](/integrations/direct-api/statuses-errors) lists every code with suggested handling.
